MY CODING JOURNEY

From my first lines of code to the things I'm building today.

I didn't start coding because I wanted a generic career in tech. I started because I wanted to understand how thoughts become software, how abstract logic commands silicon, and how one person with a text editor can build tools that didn't exist an hour ago. Every project here is a footprint: early scripts that barely ran, late-night debugging marathons, algorithmic epiphanies, and the thrill of building things that actually work.
